DEPLOYMENT:
Upload the CONTENTS of this ZIP to the GitHub repository root (not an extra enclosing folder).
Netlify publish directory should be the repository root. The homepage is index.html.

BEFORE LAUNCH:
1. Replace 91XXXXXXXXXX in the WhatsApp links with the official business number.
2. Connect the enquiry form to an approved CRM/email endpoint. The included form currently validates in the browser only and does not send leads.
3. Add verified company contact details and legally reviewed privacy/terms disclosures.
4. Do not show lender names/logos as partners unless the relationship and permissions are confirmed.
5. Loan eligibility, pricing, approval and disbursal are decided by the respective lender.
